# Entrada de assets

Põe aqui (pelo browser do GitHub: **Add file → Upload files**) os packs novos — de preferência
**um .zip por pack** (o browser só aceita 100 ficheiros por envio; um zip conta como 1).
Até 25 MB por ficheiro; acima disso usa uma **release-rascunho** do repo.

Diz no chat o que enviaste. O Claude organiza tudo em `assets/`, apaga daqui e liga ao jogo.
