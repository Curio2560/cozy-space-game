# Interface

- `scifi/` — molduras néon do **Sci-Fi Game UI FREE** (SunGraphica, sungraphica.itch.io; licença a
  confirmar) reduzidas para o telemóvel: moldura do menu de pausa, sublinhado, moldura de painel,
  moldura de célula, setas e fechar. O texto é escrito pelo jogo (PT/EN).
- `icons/` — 88 ícones brancos do mesmo pack (`icon_NN.png`, numeração do pack).
- `kenney_space/` — **Kenney Simple Space** (CC0): marcadores do minimapa.
